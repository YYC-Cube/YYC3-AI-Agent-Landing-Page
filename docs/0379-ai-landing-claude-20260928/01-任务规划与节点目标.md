# 📋 任务规划与节点目标

## 一、总体目标

技术栈全面升级对齐实况 + 开发者文档体系补全 + CI 自动化部署 GitHub Pages（ai-landing.yyc3.top）全链路闭环，推送 main。

## 二、阶段划分

| 阶段 | 名称 | 目标 | 交付物 | 状态 |
| ---- | ---- | ---- | ------ | ---- |
| Phase 1 | 依赖升级 | package.json 重写 + pnpm 安装 | package.json / pnpm-lock.yaml | ⬜ |
| Phase 2 | 配置对齐 | 静态导出/图标/ESLint/清理冗余 | next.config.mjs、eslint.config.mjs、layout.tsx | ⬜ |

## 三、详细任务分解

### Task 1: 依赖升级完善
**验收标准**:
- [ ] 仅保留实际使用依赖，全部精确版本（无 latest）
- [ ] next ^16 / react ^19.3 / @types 对齐 / TS 5.9 / Tailwind 4.3
- [ ] 新增 eslint + eslint-config-next + @types/canvas-confetti
- [ ] pnpm install 成功
**风险点**: lucide-react 1.x 图标更名 / tsparticles v4 API 变更 / framer-motion 13 变更 → 以 build 验证，逐项修复

### Task 2: 配置对齐
**验收标准**:
- [ ] next.config.mjs: output export + images.unoptimized + trailingSlash
- [ ] layout.tsx 图标指向存在的资源；metadataBase 指向 ai-landing.yyc3.top
- [ ] eslint.config.mjs（flat config）；scripts: dev(3030)/lint/typecheck/build/preview
- [ ] 删除 styles/globals.css、components/theme-provider.tsx（无引用）

### Task 3: CI 自动化 Pages 部署
**验收标准**:
- [ ] ci.yml：push/PR 触发 lint+typecheck+build
- [ ] deploy-pages.yml：main push 触发构建 → actions/deploy-pages 上线
- [ ] 使用 pnpm/action-setup + packageManager 字段 + setup-node 缓存

### Task 4: 文档体系
**验收标准**:
- [ ] README 全面重写：徽章（CI/Deploy/版本/规范）、结构/部署/端口 3030 对齐实况
- [ ] docs/YYC3-AI-LANDING-开发者规范/（106-108 + README）
- [ ] CHANGELOG.md、SECURITY.md、CODE_OF_CONDUCT.md
- [ ] 文档映射目录.md 收录新分类并修正 tailwind.config.ts 误导
